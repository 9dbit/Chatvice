# Chatvice Mail — retro workspace and attachment previews

The landing page, login, inbox, mailbox settings and scoped dialogs use a white/grey/orange/charcoal retro system, self-hosted Pixelify Sans headings and IBM Plex Mono text. Generated opaque CRT, pixel envelope and floppy-disk WebP artwork lives in `client/src/assets/mail-retro/`; `docs/mail-retro-assets.json` records each exact prompt and the built-in imagegen provenance. Font licenses are alongside the WOFF2 files.

Compose and reply accept multiple files or drag/drop without first saving manually. The app creates one private draft, preserves its ID on retry, shows photo/video thumbnails and a large right-hand preview, and supports expanded viewing. Mobile stacks the writing and attachment areas, with persistent send/save actions. PDF pages render locally through lazy-loaded PDF.js canvas; text previews are escaped and bounded. Office/unsupported documents show file metadata and a download action. Native video codecs depend on the browser. Attachment policy remains 8 files and 16 MiB aggregate per message, with existing mailbox quota and security scanning. Pending/blocked files cannot be downloaded, previewed or sent. Removal is allowed only on writable drafts and is serialized against sending.

The inbox uses an on-demand right sidebar opened by the header Menu button. Workspace selection, folders, appearance, settings and sign-out are inside that sidebar. Compose sits immediately below the header beside conversation status. All/unread/starred filters share a row with refresh and the search icon. Search expands downward, retains a visible active-filter indicator while collapsed, and supports `/` and Escape with focus restoration. The header shrinks when the list or reader scrolls and returns to normal at the top. Standard controls are 10% smaller, and desktop space is divided between list and reader; mobile shows the list or selected message. There is no bottom ticker or running-text panel.

Activity and manual subscription renewal reminders remain available from the sidebar. The drawer includes the latest 10 unread inbox **messages**, exact unread/spam/draft message counts and resumable drafts. Activity refreshes once per minute only while the panel and tab are visible. Reminders are shared within the mailbox, encrypted at rest, and can be added or completed by mailbox writers. They are in-app reminders, not inferred billing data, automatic cancellation, email notifications, or recurring payments.

The additive migration `20261101_chatvice_mail_reminders_v4.sql` is applied by the guarded isolated installer. Only exact recorded three/four-file histories or an empty isolated database may advance; unknown tables/history, changed credentials scope, checksum drift, and unrecorded reminder tables are refused. Login credentials and existing mail are preserved. Both independent app and disposable QA images package the migration. Rollback should retain the new schema installer and data (or use a forward corrective release); an older installer deliberately refuses the newer history. Do not delete reminder data to roll back styling.

Validation: frontend typecheck, production Vite builds, existing workspace and settings browser contracts, new production-CSP attachment/menu/reminder contracts at 320–2560 px, MIME-spoofing/scan-gating checks, and CI tenant-isolation, guarded migration, encrypted backup/restore and real Docker runtime checks. Browser fixtures use synthetic mail and files only. No real message is sent during validation.

PDF rendering reference: https://mozilla.github.io/pdf.js/examples/
