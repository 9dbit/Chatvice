# Chatvice - Customer Service Chatbot Platform

## Overview
Chatvice is an AI-powered customer service chatbot platform designed to automate customer support for businesses. It provides intelligent responses, seamless escalation to human supervisors, and a customizable chat widget for merchant websites. The platform includes a merchant dashboard for configuration and monitoring, and a supervisor panel for managing escalated conversations. Its primary goal is to reduce support costs while maintaining high-quality customer service through smart AI-to-human handoff mechanisms.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture
Chatvice is a monorepo application with `/client`, `/server`, and `/shared` components, featuring a multi-panel design including a Landing Page, Merchant Dashboard, Supervisor Panel, embeddable Chat Widget, and an Admin Master Panel. The UI/UX leverages Shadcn/ui and Radix UI with Tailwind CSS, utilizing a custom "new-york" theme and dark mode.

**Technology Stack:**
- **Frontend**: React with TypeScript, Vite, Wouter, TanStack Query, React Hook Form with Zod.
- **Backend**: Express.js with TypeScript, `ws` for WebSockets, `express-session`.
- **Database**: PostgreSQL with Drizzle ORM.
- **AI Integration**: OpenAI API (GPT-4.1-mini for chat, text-embedding-3-small for embeddings).

**Key Features:**
- **AI-Powered Chatbot**: Automates customer responses using semantic search from a per-agent knowledge base with conversation memory optimization. Supports multi-language and AI media analysis.
- **Human Escalation**: Automatic or manual escalation to human supervisors.
- **Configurable Chat Widget**: Embeddable, customizable widget with dynamic theming, real-time status, media upload, suggested questions, and programmatic control. Includes customer name collection, profanity filtering, input validation, and AI-generated personalized greetings. Social media integration is supported. Auto-open mode bypasses welcome bubble and name collection, greeting visitors directly with AI agent message and prechat banner.
- **AI Media Analysis**: AI analyzes uploaded images (OpenAI Vision) and documents (summarization).
- **Merchant Dashboard**: Provides analytics, knowledge base management (with web crawler and AI generation), trigger configuration, supervisor management, subscription management, quick replies, product cards, and notification settings. Includes a draggable/hideable Chatvice Guide AI assistant.
- **Supervisor Panel**: Real-time interface for handling escalated conversations and team activity monitoring.
- **Authentication & Authorization**: Session-based authentication with bcrypt, supporting Merchant and Supervisor roles with role-based permissions. OAuth via Google and GitHub.
- **Real-time Communication**: WebSocket architecture for instant message delivery and updates.
- **Per-Agent Knowledge Base & System Prompt**: Knowledge base content and customizable AI system prompts are scoped to individual AI agents.
- **Widget Identity Verification**: Secure customer authentication for embedded widgets using JWT tokens.
- **Work Scheduler**: Shift management system for supervisors and AI agents.
- **Landing Page & Feature Configuration**: Admin Panel allows non-technical customization of the public landing page and configuration of all plan feature limits (conversations, AI agents, supervisors, knowledge sources, etc.).
- **Promotional Discount System**: Comprehensive promo code system with admin CRUD, plan targeting, and usage limits.
- **Chat Security Monitoring**: AI-powered monitoring of supervisor conversations to detect suspicious activities using Gemini 2.5 Flash, with configurable sensitivity and real-time alerts.
- **Knowledge Base Management**: Unified system with Training Data (multi-entry knowledge), Active Sources (URL sources with auto-sync), and Create with AI (AI-generated articles). Supports templates, auto-sync for crawled content, drag-and-drop card reordering (via @dnd-kit), and AI auto-formatting of knowledge content on save.
- **Product Catalog Crawler**: AI-powered product scanning system for intelligent product recommendations. Uses Puppeteer for screenshots sent to OpenAI Vision (GPT-4.1) for product extraction, with mandatory human review.
- **Custom Plan Request System**: Interactive budget simulator for merchants to configure and request custom plans.
- **Closing Statement Feature**: Automatic or manual closing statements when chat becomes inactive, configurable to include business and customer names.
- **Automatic Chat Cleanup**: Background job for archiving expired sessions and generating chat logs with full transcripts based on plan retention policies.
- **Smart Notification Sound System**: Context-aware audio alerts for incoming chats, replies, and "angry" alerts, with user-specific preferences.
- **Affiliate Withdrawal Request System**: Complete affiliate payout system with saved payment methods, withdrawal workflow, minimum payout, and admin approval.
- **Merchant Analytics & Filtering System**: Comprehensive admin filtering for Master Control Panel with 12+ filter categories and analytics API providing total spending, team counts, average ratings, response times, and escalation rates.
- **Customer Chat Platform (chat.chatvice.app)**: Separate customer-facing mobile chat app with subdomain-based routing and two-tier authentication (WhatsApp/SMS OTP for first-time, phone+PIN for returning users).
- **External Chat Bridge API**: Endpoints for sending customer messages to merchants and retrieving replies, secured via API key and CORS.
- **Google Sheet Transaction Lookup**: AI agent detects transaction queries and performs real-time Google Sheet fetches to inject structured data into the prompt for accurate lookups.
- **Base64 Image Serving Endpoints**: Dedicated endpoints for serving merchant and supervisor base64-encoded images stored in the database as binary responses with caching.
- **Live Visitor Tracking & Proactive Chat**: Real-time website visitor tracking with IP geolocation (ip-api.com with in-memory cache). Supervisors see live visitors with country flags and can initiate proactive conversations before visitors start chatting. Widget auto-opens when supervisor sends a message. Feature is toggleable per-merchant via dashboard settings.
- **Visitor Info Panel**: Toggleable right-side panel in the supervisor chat session view (activated via the Info button in the chat header). Displays IP address (with copy button), country flag + city/country name, device/OS/browser icons + user agent, current page URL, and traffic source (referrer URL or "Direct / Unknown"). Referrer URL is captured from `document.referrer` in both the embedded widget JS (visitor-ping) and the React widget (start-chat), stored in the `referrer_url` column on the `sessions` table (added via schema migration).
- **Two-Way Telegram Supervisor Bridge**: Supervisors can link their Telegram Chat ID in the Notifications page of the Supervisor Panel. When chats are escalated, the merchant's Telegram bot sends a DM to each linked supervisor with context and recent messages. Supervisors reply to the Telegram message to respond to customers in real-time. Customer messages in HUMAN-mode sessions are forwarded to linked supervisors' Telegram DMs. Merchants enable this via the Integrations page "Enable Supervisor Telegram Replies" button which sets up the Telegram webhook. Schema: `supervisors.telegramChatId` (text), `messagingBridgeSessions` table (anchorMessageId-based routing). Endpoints: `POST /api/telegram/webhook/:merchantId`, `PATCH /GET /api/supervisor/telegram`, `POST /api/merchant/telegram/setup-webhook`.
- **Hospitality Add-on ($12/month)**: AI Hotel Availability Checker with real-time Google Sheet integration. Merchant configures hotel name, booking URL, Google Sheet (columns: room_name, price_per_night, availability, image_url), and AI instructions. AI detects hotel queries via `[HOTEL_QUERY_DETECTED]` signal, backend fetches/caches CSV data (10-min TTL), parses room data, and sends `hotelOptions` message type. Widget renders horizontal-scroll room cards with "Harga Terbaik" badge (cheapest), "Hampir Penuh" badge (<3 rooms), availability color-coding, and "Pesan Sekarang" CTA button. Settings UI accessible via Additional Services → Manage. DB: `hospitality_configs` table. Schema: `hospitalityConfigs` in shared/schema.ts.
- **Additional Services (formerly "Layanan Tambahan")**: Renamed to "Additional Services" throughout. Payment flow now uses real Kompas Pay QRIS via `POST /api/merchant/addons/initiate-payment` (shows scannable QR code). PayPal/Crypto uses manual reference flow. 7-day free trial via `POST /api/merchant/addons/start-trial` (one trial per addon type). `merchant_addons` schema gains `trial_ends_at` and `payment_reference` columns. Webhook handler (`kompasPayWebhook.ts`) detects `metadata.type === "addon"` and auto-activates addons. Admin MCP tab shows Trial Ends date and countdown badge. Auth bug fixed: 401 responses no longer immediately redirect to login (queryClient default changed from `throw` to `returnNull`).
- **Widget Domain Security & Approval Flow**: Server-side domain whitelist enforcement on all four public widget endpoints (`/api/widget/chatvice.js`, `/api/widget/resolve/:slugOrId`, `/api/widget/visitor-ping`, `/api/widget/start-chat`). Grace period applies when merchant has zero validated domains (widget works on any domain, attempts are still recorded). Once any validated domain is registered, strict enforcement kicks in — requests from unknown domains receive HTTP 403 and are recorded in `unknown_domain_attempts`. Domain extraction: `null`=same-origin (always allow), `""`=unknown/absent origin (deny if validated domains exist), `"foo.com"`=external (whitelist check). Replit `*.replit.dev`/`*.repl.co`/`*.replit.app` domains are dev-mode-only bypasses (blocked in production). DB: `unknown_domain_attempts` table with unique index on `(merchant_id, domain)`. Dashboard Widget → Embed tab shows "Unregistered Domains" panel with per-attempt Approve/Dismiss. Approve promotes domain to `merchant_domains` with `isValidated=true`. Sidebar shows red count badge. Endpoints: `GET /api/merchant/domains/unknown`, `GET /api/merchant/domains/unknown/count`, `POST /api/merchant/domains/unknown/:id/approve`, `DELETE /api/merchant/domains/unknown/:id`.
- **Competitor Comparison Pages**: SEO-optimized landing pages at `/vs/[competitor]` for 7 competitors (Tawk.to, Intercom, Tidio, Zendesk, Freshdesk, LiveChat, Drift). Each page has feature comparison table, differentiators, pricing comparison, FAQ JSON-LD schema, internal cross-links, and CTA sections. Footer has a "Compare" column. Sitemap and OG image config updated. Files: `client/src/pages/comparison/competitors-data.ts`, `client/src/pages/comparison/comparison-page.tsx`.
- **Indonesian Long-Tail SEO Pages**: 7 additional pages targeting city-specific and industry-specific keywords. City pages: `/chatbot-jakarta`, `/chatbot-surabaya`, `/chatbot-bandung`. Industry pages: `/chatbot-restoran`, `/chatbot-klinik`, `/chatbot-properti`, `/chatbot-pendidikan`. All use the existing `SolutionPage` component pattern. Data in `client/src/pages/solutions/solutions-data.tsx` (exported as `cityPagesData`, `industryPagesData`). All linked from the footer Solutions section and cross-linked internally via `relatedSlugs`.
- **AI Auto-Post Blog System**: Daily AI-generated blog content using GPT-4.1-mini. Generates 5 posts/day (1 per category: Product, Tutorial, Industry, Comparison, Insights) at 01:00 UTC. Comparison posts rotate 8 competitors (LiveChat→Tawk.to→Chatport→Freshdesk→Zendesk→Intercom→Tidio→Drift) by day. Idempotent: skips already-generated categories for the day. DB-backed blog pages fetch from PostgreSQL with static fallback. Admin Blog Management UI in Master Panel with publish/feature toggles, delete, manual trigger, and generation logs. Tables: `blog_posts`, `blog_generation_logs`. Server: `blog-generator.ts`. APIs: `GET /api/blog/posts`, `GET /api/blog/posts/:slug`, `GET /api/blog/categories`, `GET/PATCH/DELETE /api/admin/blog/posts`, `POST /api/admin/blog/generate`, `GET /api/admin/blog/logs`.
