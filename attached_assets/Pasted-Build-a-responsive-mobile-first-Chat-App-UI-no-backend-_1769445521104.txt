Build a responsive mobile-first Chat App UI (no backend needed) inspired by modern flat social chat design.

Tech stack:
- React + TypeScript + Vite
- TailwindCSS
- React Router
- Use only local dummy data (JSON) for contacts and messages
- Make it look like an iOS-style app screen in a centered phone frame on desktop

UI Style requirements (very important):
- Primary brand color: purple/indigo gradient header (top bar) similar to #4B2CFF → #5B5CFF
- Clean flat UI, soft shadows, rounded corners (16–24px)
- White message cards on light grey background (#F4F5F7)
- Avatar circles, bold contact name, small preview text
- Friendly typography (use Inter or system font)
- Spacing should feel premium and breathable

Pages / Routes:
1) /inbox
   - Gradient header with title “Inbox”
   - A horizontal “Favorite Contact” avatar row under the header
   - Below it: chat list items (each item: avatar, name, preview text, time on the right, unread badge)
   - Floating action button (+) bottom-right
   - List items are white rounded cards with subtle shadow

2) /chat/:id
   - Gradient header with back button and contact name centered
   - Chat messages area with:
     - Incoming messages: white rounded bubble, aligned left
     - Outgoing messages: purple bubble (#4B2CFF), aligned right, white text
   - Message composer at bottom:
     - rounded input field
     - send button as a circular icon button on the right
   - Emoji panel docked at bottom (like a drawer):
     - a rounded purple panel with a grid of emojis
     - can be toggled open/close with an emoji button near the input
   - Smooth transitions (drawer slide up/down)

Data model:
- contacts: id, name, avatarUrl (use placeholder), lastMessage, lastTime, unreadCount, isFavorite
- messages: id, contactId, text, time, sender ("me" or "them")

Components to create:
- PhoneFrame (centered mobile container with rounded outer border and shadow)
- GradientHeader
- FavoriteRow
- ChatListItem
- MessageBubble
- Composer
- EmojiDrawer

Extra:
- Add a light background with subtle dots or noise pattern (optional)
- Make sure it looks good on iPhone size (390x844)
- Provide complete source code with clear folder structure
- The UI must match the reference style: soft rounded cards, purple gradient top bar, clean minimal layout
