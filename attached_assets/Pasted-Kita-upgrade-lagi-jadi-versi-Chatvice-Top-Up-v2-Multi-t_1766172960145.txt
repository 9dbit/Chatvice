2. Tracking Domain Dinamis
2.1. Cara sistem tahu domain apa yang sedang dipakai?
Saat widget di-embed:
Snippet widget di merchant akan memanggil endpoint inisialisasi:
POST /api/widget/init
Body:
{
  "site_key": "PUBLIC_WIDGET_KEY",
  "current_domain": "gamexyzz123.com"
}

site_key = identitas tetap untuk site itu (dibagi saat setup merchant).
Backend:
Cari site berdasarkan site_key.
Cek tabel site_domains:
kalau current_domain belum ada:
insert new history row,
set sebagai is_current = true,
yang sebelumnya is_current = false.
kalau sudah ada:
update last_seen_at,
set is_current = true dan lainnya = false.
Domain terbaru ini disimpan & akan:
dipakai di token topup,
dipakai jadi komponen order_id,
muncul di Master & Merchant Dashboard.
2.2. Desain tabel domain history
Tabel site_domains:
id
site_id
domain (ex: gamexyz.com, gamexyz123.com)
first_seen_at
last_seen_at
is_current (boolean)
Aturan:
Satu site_id bisa punya banyak row domain.
Hanya satu yang is_current = true (domain aktif saat ini).
Domain pertama yang ditemukan ≈ “domain pertama embed”.

3. Workflow Lengkap (End-to-End)
3.1. Tahap 1: Widget inisialisasi & tracking domain
Merchant embed script widget di halaman mereka.
Saat halaman load, widget melakukan:
POST /api/widget/init {
  "site_key": "PUBLIC_WIDGET_KEY",
  "current_domain": window.location.hostname
}

Backend:
Validasi site_key.
Resolve ke merchant_id, site_id, site_code.
Update site_domains:
jika domain baru → insert + mark current.
Kembalikan konfigurasi awal ke widget (opsional):
site info,
apakah topup di-enable,
dsb.
3.2. Tahap 2: Chat Mode → detect niat top up
User chat:
“koin saya habis nih”
Agent (Chat Mode) mendeteksi niat topup, lalu bertanya:
“Mau saya bantu proses login dan pembelian koin, kak?”
User jawab: “ya”, “mau”, “ok”, dst.
Agent switch ke Payment Mode:
“Baik kak, saya bantu proses top up ya. Nanti akan muncul tampilan penuh untuk pilih nominal dan metode pembayaran.”
Front-end widget di sisi UI:
memanggil POST /api/start-topup.
3.3. Tahap 3: Start top-up & generate JWT + redirect URL
POST /api/start-topup body:
{
  "site_key": "PUBLIC_WIDGET_KEY",
  "user_id": "USER123",
  "return_url": "https://gamexyzz123.com/home"
}

Backend:
Cari site lewat site_key:
dapat site_id, merchant_id, site_code.
Cari current_domain untuk site_id dari site_domains (is_current = true).
Validasi return_url:
optional: hanya cek bahwa host di return_url sama dengan current_domain (atau tidak dicek kalau domain sering banget ganti, terserah risk level-mu).
Bentuk payload JWT:
{
  merchant_id,
  site_id,
  site_code,
  current_domain,   // <—— penting
  user_id,
  return_url,
  iat,
  exp
}

Sign dengan JWT_SECRET.
Bentuk redirect:
https://pay.chatvice.com/topup?token=SIGNED_TOKEN

Balikkan ke widget:
{
  "success": true,
  "redirect_url": "https://pay.chatvice.com/topup?token=..."
}

Widget:
animasi full screen,
load URL redirect tersebut di iframe / window.
3.4. Tahap 4: Payment UI → pilih nominal & metode
Di GET /topup?token=...:
Backend verifikasi token.
Extract:
merchant_id,
site_id,
site_code,
current_domain,
user_id,
return_url.
Render halaman full screen:
header: nama game, domain (opsional),
step: pilih nominal (25k, 50k, 100k, 200k, 500k),
optional: pilih channel (AUTO/QRIS/VA/EWALLET/etc).
Ketika user pilih nominal & klik “Lanjut Bayar”:
front-end panggil POST /api/payment/create-order.
3.5. Tahap 5: Create order, call Kompas Pay
POST /api/payment/create-order body:
{
  "token": "JWT_TOKEN",
  "amount": 100000,
  "channel": "AUTO"
}

Backend:
Verifikasi token (lagi).
Ambil site_code, current_domain, site_id, merchant_id, user_id, return_url.
Validasi nominal.
Generate order_id dengan site & domain aware:
Ambil domTag dari current_domain, misal:
ambil domain tanpa TLD → gamexyzz123,
ambil 3–5 karakter awal → GAMEX,
atau hash pendek: D123.
Format:
const order_id = `CVT-${site_code}-${domTag}-${Date.now()}-${rand3}`;

Contoh:
CVT-GXZ-GAMEX-1734683245123-A7F

Simpan order:
{
  order_id,
  merchant_id,
  site_id,
  user_id,
  amount,
  channel_requested,
  payment_type: null,
  payment_data: null,
  status: "PENDING",
  current_domain,   // <— dicatat juga di order
  return_url,
  created_at: now
}

Call Kompas Pay dengan order_id ini:
order_id = CVT-GXZ-GAMEX-...
amount, channel, callback_url, dsb.
Dapat response:
payment_type (QRIS, VA, dsb),
payment_data (QR, VA number, link, dll),
gateway_ref.
Update order:
payment_type,
payment_data,
gateway_ref.
Kembalikan payment_instruction generik ke UI (untuk ditampilkan).
3.6. Tahap 6: Pembayaran & webhook
User bayar via channel yang disediakan.
Kompas Pay kirim webhook ke POST /webhook/kompaspay:
{
  "order_id": "CVT-GXZ-GAMEX-1734683245123-A7F",
  "status": "PAID",
  "amount": 100000,
  "payment_type": "QRIS",
  "payment_ref": "KP-XYZ",
  "signature": "..."
}

Backend:
Verifikasi signature.
Cari order by order_id.
Cocokkan amount.
Update status → PAID.
Cari site (punya coin_api_base_url, coin_api_secret).
Call API merchant untuk credit coin:
body:
{
  "user_id": "USER123",
  "amount": 100000,
  "order_id": "CVT-GXZ-GAMEX-...",
  "domain": "gamexyzz123.com",
  "signature": "HMAC(user_id+amount+order_id+domain, coin_api_secret)"
}


Jika sukses:
order.status = "COMPLETED", set credited_at.
Jika gagal:
order.status = "PAID_BUT_NOT_CREDITED".
3.7. Tahap 7: Result page & kembali ke domain
Frontend pay.chatvice.com bisa polling GET /api/payment/status?order_id=... atau redirect ke /topup/result?order_id=....
Di /topup/result:
Kalau COMPLETED → tampil sukses + CTA “Lanjut ke beranda”.
CTA redirect ke return_url.

2. Payment Mode → memandu alur top up saldo/koin secara aman dan terstruktur.

====================================
MODE OPERASI
====================================

1. Chat Mode
------------------------------------
- Digunakan untuk:
  - tanya fitur,
  - masalah login (secara konsep),
  - info game,
  - FAQ, dsb.
- Jawaban boleh lebih bebas, sopan, dan konteksnya relevan dengan website tempat widget dipasang.
- Di Chat Mode, kamu harus mendeteksi niat user untuk top up, misalnya jika user bilang:
  - "koin saya habis",
  - "mau isi saldo",
  - "beli koin",
  - "top up dong",
  - "cara isi diamond", dan sejenisnya.

Jika user menunjukkan niat top up:
- Jangan langsung memulai transaksi.
- Tanyakan konfirmasi eksplisit, seperti:
  "Mau saya bantu proses login dan pembelian koin, kak?"

Jika user menjawab persetujuan (misalnya "iya", "ya", "ok", "oke", "mau", "boleh", "lanjut", "y"):
- Anggap user setuju untuk memulai proses top up.
- Saat itu, front-end akan mengubah tampilan ke mode pembayaran (full screen). Kamu cukup menjelaskan prosesnya, tidak perlu membuat URL sendiri.

2. Payment Mode
------------------------------------
- Dipicu setelah user setuju atas tawaran:
  "Mau saya bantu proses login dan pembelian koin, kak?"
- Di Payment Mode, kamu bertindak sebagai “wizard transaksi”:
  - jelaskan langkah singkat: pilih nominal → pilih metode bayar → bayar → saldo masuk.
  - tawarkan pilihan nominal top up:
    - 25.000, 50.000, 100.000, 200.000, 500.000 (disajikan sebagai opsi/tombol).
  - minta konfirmasi sebelum melanjutkan ke pembayaran:
    - "Kamu akan top up Rp[XXX]. Lanjut bayar?"
  - informasikan bahwa pembayaran dilakukan di halaman resmi yang aman.

- Di Payment Mode, batasi percakapan:
  - gunakan tombol/quick reply jika bisa,
  - kalau user melenceng topik, jawab singkat lalu tarik kembali ke flow:
    "Saat ini kita sedang proses top up saldo. Mau lanjut selesaikan transaksi dulu, atau batal dan kembali ke mode chat biasa?"
    dengan opsi:
    - [Lanjutkan Top Up]
    - [Batalkan Top Up]

- Jangan pernah:
  - meminta atau menerima nomor kartu kredit, CVV, OTP, PIN, private key, seed phrase.
  - mengarang status pembayaran (misalnya mengaku “sudah berhasil” tanpa info sistem).

====================================
METODE PEMBAYARAN
====================================

Sistem pembayaran di backend mendukung berbagai metode (via Kompas Pay), seperti:
- QRIS
- Transfer bank
- Virtual Account (VA)
- E-wallet
- dan pengembangan berikutnya: kartu kredit, crypto.

Peran kamu:
- Hanya menjelaskan secara konsep, misalnya:
  "Di halaman pembayaran, kakak bisa pilih metode seperti QRIS, VA, e-wallet, atau transfer bank."
- Instruksi teknis dan data spesifik (QR code, nomor VA, nomor rekening, alamat crypto) akan diberikan oleh backend/UI, bukan oleh kamu.

====================================
ALUR TOP UP (PERSPEKTIF AGENT)
====================================

1. Deteksi user ingin top up.
2. Tanyakan:
   "Mau saya bantu proses login dan pembelian koin, kak?"
3. Jika user setuju:
   - Jelaskan singkat:
     "Baik kak, saya bantu proses top up. Nanti akan muncul tampilan penuh untuk pilih nominal dan metode pembayaran. Setelah pembayaran berhasil, koin akan otomatis masuk."
4. Tawarkan pilihan nominal (25k–500k).
5. Setelah nominal dipilih, konfirmasi:
   - "Kamu akan top up Rp[XXX]. Lanjut bayar?"
6. Setelah user konfirmasi:
   - Jelaskan bahwa sistem akan menyiapkan order dan halaman pembayaran resmi.
7. Setelah backend mengkonfirmasi pembayaran sukses:
   - Sampaikan:
     - "Pembayaran berhasil, koin/saldo sudah ditambahkan ke akun kakak."
   - Tawarkan untuk kembali ke beranda atau melanjutkan bermain.

Jika terjadi error:
- Jelaskan singkat dan sopan.
- Tawarkan untuk coba lagi atau kembali ke Chat Mode.

ATURAN UMUM

- Jangan mengumpulkan data finansial rahasia di chat.
- Jangan mengarang status pembayaran.
- Jaga Payment Mode tetap pendek, jelas, dan fokus pada alur transaksi.
- Pastikan ada penutupan flow:

6. Skeleton Kode Replit (Express.js, ringkas tapi mengandung semua logika kunci)
Catatan: ini skeleton, beberapa bagian pseudo (misalnya DB dan Kompas Pay) kamu sambungkan ke implementasi asli.
// app.js

import express from "express";
import bodyParser from "body-parser";
import jwt from "jsonwebtoken";

const app = express();
app.use(bodyParser.json());

const JWT_SECRET = process.env.JWT_SECRET || "CHANGE_ME";
const KOMPAS_PAY_SECRET = process.env.KOMPAS_PAY_SECRET || "CHANGE_ME";

const merchants = new Map();   // merchant_id -> merchant
const sites = new Map();       // site_key -> site
const siteDomains = new Map(); // site_id -> array of domains
const orders = new Map();      // order_id -> order

// ===== Helper JWT =====
function generateTopupToken(payload) {
  return jwt.sign(payload, JWT_SECRET, { expiresIn: "10m" });
}

function verifyTopupToken(token) {
  try {
    return jwt.verify(token, JWT_SECRET);
  } catch {
    return null;
  }
}

// ===== Helper domain history =====
function upsertSiteDomain(site_id, domain) {
  const list = siteDomains.get(site_id) || [];
  const now = new Date().toISOString();

  let found = null;
  for (const d of list) {
    if (d.domain === domain) {
      found = d;
      break;
    }
  }

  // set all is_current = false dulu
  for (const d of list) {
    d.is_current = false;
  }

  if (!found) {
    const newRow = {
      id: `SD_${site_id}_${list.length + 1}`,
      site_id,
      domain,
      first_seen_at: now,
      last_seen_at: now,
      is_current: true
    };
    list.push(newRow);
  } else {
    found.last_seen_at = now;
    found.is_current = true;
  }

  siteDomains.set(site_id, list);
}

function getCurrentDomain(site_id) {
  const list = siteDomains.get(site_id) || [];
  const current = list.find(d => d.is_current);
  return current ? current.domain : null;
}

// ===== Helper order =====

function createOrder(order) {
  orders.set(order.order_id, order);
}

function getOrder(order_id) {
  return orders.get(order_id);
}

function updateOrder(order_id, patch) {
  const existing = orders.get(order_id);
  if (!existing) return;
  orders.set(order_id, { ...existing, ...patch });
}

function makeDomTag(domain) {
  if (!domain) return "UNKNOWN";
  const base = domain.split(".")[0]; // ambil sebelum TLD
  return base.toUpperCase().slice(0, 5); // max 5 char
}

// ===== 1) WIDGET INIT: track domain =====

app.post("/api/widget/init", (req, res) => {
  const { site_key, current_domain } = req.body;

  if (!site_key || !current_domain) {
    return res.status(400).json({
      success: false,
      message: "site_key dan current_domain wajib diisi"
    });
  }

  const site = sites.get(site_key);
  if (!site || site.status !== "ACTIVE") {
    return res.status(404).json({
      success: false,
      message: "Site tidak ditemukan atau tidak aktif"
    });
  }

  upsertSiteDomain(site.site_id, current_domain);

  return res.json({
    success: true,
    site_code: site.site_code,
    merchant_id: site.merchant_id,
    topup_enabled: true
  });
});

// ===== 2) START TOPUP =====

app.post("/api/start-topup", (req, res) => {
  const { site_key, user_id, return_url } = req.body;

  if (!site_key || !user_id || !return_url) {
    return res.status(400).json({
      success: false,
      message: "site_key, user_id, return_url wajib diisi"
    });
  }

  const site = sites.get(site_key);
  if (!site || site.status !== "ACTIVE") {
    return res.status(404).json({
      success: false,
      message: "Site tidak ditemukan atau tidak aktif"
    });
  }

  const current_domain = getCurrentDomain(site.site_id);
  if (!current_domain) {
    return res.status(400).json({
      success: false,
      message: "Domain current untuk site ini belum tercatat"
    });
  }

  const payload = {
    merchant_id: site.merchant_id,
    site_id: site.site_id,
    site_code: site.site_code,
    current_domain,
    user_id,
    return_url
  };

  const token = generateTopupToken(payload);
  const redirect_url = `https://pay.chatvice.com/topup?token=${encodeURIComponent(token)}`;

  return res.json({
    success: true,
    redirect_url
  });
});

// ===== 3) PAYMENT UI: GET /topup =====

app.get("/topup", (req, res) => {
  const { token } = req.query;
  if (!token) return res.status(400).send("Token tidak ditemukan.");

  const decoded = verifyTopupToken(token);
  if (!decoded) return res.status(401).send("Token tidak valid atau kadaluarsa.");

  // Render HTML sederhana, nanti kamu ganti dengan template/React
  res.send(`
    <html>
      <body>
        <h1>Top Up Koin</h1>
        <p>Site: ${decoded.site_code} (${decoded.current_domain})</p>
        <p>User: ${decoded.user_id}</p>

// ===== 4) CREATE ORDER =====

app.post("/api/payment/create-order", async (req, res) => {
  const { token, amount, channel } = req.body;

  if (!token || !amount) {
    return res.status(400).json({
      success: false,
      message: "token dan amount wajib diisi"
    });
  }

  const decoded = verifyTopupToken(token);
  if (!decoded) {
    return res.status(401).json({
      success: false,
      message: "Token tidak valid atau kadaluarsa"
    });
  }

  const allowedAmounts = [25000, 50000, 100000, 200000, 500000];
  if (!allowedAmounts.includes(amount)) {
    return res.status(400).json({
      success: false,
      message: "Nominal tidak valid"
    });
  }

  const paymentChannel = channel || "AUTO";
  const domTag = makeDomTag(decoded.current_domain);
  const rand3 = Math.random().toString(36).substring(2, 5).toUpperCase();

  const order_id = `CVT-${decoded.site_code}-${domTag}-${Date.now()}-${rand3}`;

  const order = {
    order_id,
    merchant_id: decoded.merchant_id,
    site_id: decoded.site_id,
    user_id: decoded.user_id,
    current_domain: decoded.current_domain,
    amount,
    channel_requested: paymentChannel,
    payment_type: null,
    payment_data: null,
    status: "PENDING",
    gateway_ref: null,
    return_url: decoded.return_url,
    created_at: new Date().toISOString()
  };

  createOrder(order);

  // TODO: call Kompas Pay API
  const kompasResponse = {
    status: "OK",
    payment_type: "QRIS",
    payment_data: {
      qris_image_url: "https://example.com/qris.png",
      qris_payload: "000201..."
    },
    gateway_ref: "KP-XYZ"
  };

  if (kompasResponse.status !== "OK") {
    return res.status(500).json({
      success: false,
      message: "Gagal membuat instruksi pembayaran"
    });
  }

  updateOrder(order_id, {
    payment_type: kompasResponse.payment_type,
    payment_data: kompasResponse.payment_data,
    gateway_ref: kompasResponse.gateway_ref
  });

  let payment_instruction = {
    display_type: "QR_CODE",
    title: "Bayar dengan QRIS",
    message: "Scan QR berikut menggunakan aplikasi bank/e-wallet.",
    data: kompasResponse.payment_data
  };

  return res.json({
    success: true,
    order_id,
    payment_type: kompasResponse.payment_type,
    payment_instruction
  });
});

// ===== 5) WEBHOOK KOMPAS PAY =====

app.post("/webhook/kompaspay", (req, res) => {
  const payload = req.body;

  // TODO: verifikasi signature dengan KOMPAS_PAY_SECRET
  const { order_id, status, amount, payment_type, payment_ref } = payload;

  const order = getOrder(order_id);
  if (!order) {
    console.log("Order tidak ditemukan:", order_id);
    return res.status(200).send("OK");
  }

  if (order.status === "COMPLETED" || order.status === "PAID_BUT_NOT_CREDITED") {
    return res.status(200).send("OK");
  }

  if (status === "PAID") {
    updateOrder(order_id, {
      status: "PAID",
      paid_at: new Date().toISOString(),
      payment_ref,
      payment_type: payment_type || order.payment_type
    });

    // TODO: call API merchant untuk credit coin/saldo
    // gunakan order.site_id, order.user_id, order.amount, order.current_domain
    const creditSuccess = true; // ganti dengan hasil call sebenarnya

    if (creditSuccess) {
      updateOrder(order_id, {
        status: "COMPLETED",
        credited_at: new Date().toISOString()
      });
    } else {
      updateOrder(order_id, {
        status: "PAID_BUT_NOT_CREDITED"
      });
    }
  } else if (status === "FAILED" || status === "EXPIRED") {
    updateOrder(order_id, { status });
  }

  return res.status(200).send("OK");
});

// ===== 6) RESULT PAGE =====

app.get("/topup/result", (req, res) => {
  const { order_id } = req.query;
  if (!order_id) return res.status(400).send("order_id tidak diberikan");

  const order = getOrder(order_id);
  if (!order) return res.status(404).send("Order tidak ditemukan");

  if (order.status === "COMPLETED") {
    return res.send(`
      <html>
        <body>
          <h1>Top Up Berhasil</h1>
          <p>Pembayaran berhasil dan saldo/koin sudah ditambahkan.</p>
          <a href="${order.return_url}">Lanjut ke beranda/home page</a>
        </body>
      </html>
    `);
  }

  if (order.status === "PENDING" || order.status === "PAID") {
    return res.send(`
      <html>
        <body>
          <h1>Menunggu Konfirmasi</h1>
          <p>Pembayaran kamu masih diproses. Silakan cek beberapa saat lagi.</p>
        </body>
      </html>
    `);
  }

  return res.send(`
    <html>
      <body>
        <h1>Top Up Gagal / Kadaluarsa</h1>
        <p>Status order: ${order.status}</p>
        <p>Silakan coba lagi dari awal.</p>
      </body>
    </html>
  `);
});
